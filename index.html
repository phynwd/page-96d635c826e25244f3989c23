客户端选择（官网重点）

彩色狗不强制单一 App。请按系统选择主流客户端，再使用面板中的订阅地址导入。下列组合经过长期验证，稳定性优于随机搜索到的破解包。

Windows

推荐 Clash Verge Rev 或 v2rayN。导入 Clash 订阅后开启系统代理，浏览器无需再装插件。远程桌面与开发环境可勾选 TUN 模式。

macOS

轻量用户用 ClashX Meta；需要规则分流与网关模式用 Surge。菜单栏可一键切换彩色狗香港或日本节点。

Android

推荐 Clash Meta for Android。先允许 VPN 权限，再粘贴订阅。分应用代理可只加速浏览器与会议软件，节省流量。

iOS / iPadOS

常用 Shadowrocket、Stash 或 Quantumult X。TestFlight 与 App Store 版本均可导入彩色狗通用订阅。蜂窝网络下建议关闭 UDP 阻断检测。

路由器 / NAS

OpenWrt 使用 OpenClash 或 PassWall 2，群晖可用 Container Manager 部署 Clash Meta。适合全家设备共享一条旗舰或团队订阅。

常见问题

彩色狗是机场还是 VPN？和普通加速器有何不同？

彩色狗 ColorfulDog 同时提供机场订阅与 VPN 加速能力：一份订阅可在 Clash 等客户端中当梯子使用，也可按节点做游戏与视频加速。与捆绑广告的免费加速器不同，节点、流量与设备数在套餐中写明，配置由用户本地客户端完成。

如何从官网完成客户端下载并导入订阅？

先在本页客户端选择区确认系统对应软件名称，再到该软件的正式发布渠道安装。打开彩色狗面板复制订阅 URL，在客户端中选择从 URL 导入并更新。不要下载名称含「破解」「无限流量」的安装包。

基础版、旗舰版、团队版该怎么选？

个人轻度访问选基础版；需要原生流媒体、IPLC 游戏加速和优先工单选旗舰版；多人同时在线、需要专属带宽或定制路由选团队版。三档节点协议相同，差别在流量、设备数与线路优先级。

流量如何计算？看视频会不会很快用完？

流量按出站实际字节计，含视频、会议与下载。基础版 100GB 适合浏览与文档；高清点播或大仓库克隆建议旗舰 300GB 或团队 1000GB。规则模式下访问国内站点通常不走代理，不计入套餐。

支持哪些流媒体与游戏加速？

旗舰与团队强调全节点原生解锁，常见国际视频与直播按地区线路匹配。游戏加速依赖 IPLC 与 Game 节点，适合对延迟敏感的对战与语音。基础版提供基础解锁，热门版权库在高峰期可能不如旗舰稳定。

超过设备数或需要企业分流怎么办？

同时在线超过套餐上限时，新设备会连接失败或挤占旧会话。可升级团队版至 20 台，或在面板断开闲置终端。企业定制路由、固定出口与分部门策略仅团队版提供，由专属客户经理对接。
